# SimpleTicTacToe

**SimpleTicTacToe** — это веб-приложение для игры в крестики-нолики. Пользователю нужно всего лишь зайти на сервер и дождаться игры. Когда противник будет найден, игра начнётся автоматически.

## Основные функции

- **Автоматический поиск игры**: После подключения сервер автоматически находит оппонента и уведомляет пользователя о начале матча.
- **Простота использования**: Для начала новой игры достаточно нажать кнопку "Новая игра".
- **Асинхронный сервер**: Серверная часть написана на Python с использованием WebSockets и asyncio, что обеспечивает быструю и асинхронную обработку запросов.
- **Клиентская часть**: Фронтенд реализован с помощью Nginx, HTML и JavaScript.

## Архитектура

- **Серверная часть**: Написана на Python с использованием WebSockets и asyncio, развёрнута в Docker-контейнере.
- **Клиентская часть**: Состоит из Nginx-сервера, HTML-страницы и JavaScript для взаимодействия с сервером.
- **Контейнеризация**: Приложение полностью контейнировано с использованием Docker и управляется с помощью Docker Compose.

## Запуск приложения

Для запуска приложения выполните следующие шаги:

1. Клонируйте репозиторий:
   ```bash
   git clone <URL вашего репозитория>
2. Перейдите в каталог проекта(с файлом docker-compose)
3. Выполните команду:
   ```bash
   docker-compose up --build
4. Откройте браузер и перейдите по адресу: http://localhost (чтобы началась игра зайдите на сайт с другого браузера или с новой вкладки, чтобы увидеть работу)
